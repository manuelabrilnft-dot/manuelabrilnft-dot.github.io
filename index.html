Scuba Chat

JavaDistributed SystemsNetworking

A peer to peer chat application for an ad hoc wireless network. There is no server. Nodes share one radio channel, discover each other, and forward messages so that two nodes out of range can still talk.

  • Token passing protocol to keep a shared channel collision free
  • Neighbour discovery and multi hop routing in a 2 byte header
  • Dynamic address assignment, fragmentation and acknowledgements

Blackjack Simulator

ReactJavaScriptMonte Carlo

A blackjack simulator that computes a basic strategy table from scratch instead of hardcoding one. It deals hundreds of random shoes per decision, plays every action to the end, and keeps whichever has the best expected value.

  • Monte Carlo expected value engine over 6 decks
  • Side bet analysis across 150,000 simulated deals
  • Session simulator reporting profit, return to player and win rate
